# vibe-life 3

FPS 3D singleplayer para navegador. Fan project de Half-Life 3.

**Stack:** TypeScript estricto · Vite · Three.js 0.164 · Rapier3D-compat 0.14

## Inicio rápido

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

## Controles

| Tecla             | Acción                    |
| ----------------- | ------------------------- |
| `Click`           | Capturar mouse            |
| `WASD`            | Mover                     |
| `Mouse`           | Mirar                     |
| `Espacio`         | Saltar                    |
| `Click izquierdo` | Disparar / golpear        |
| `1`–`5`, rueda    | Cambiar de arma           |
| `R`               | Recargar                  |
| `E`               | Interactuar               |
| `F3`              | Debug overlay             |
| `Esc`             | Pausar / liberar mouse    |

La arquitectura, patrones, reglas y guías de extensión están documentados en [CLAUDE.md](./CLAUDE.md).
